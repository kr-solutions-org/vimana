# VIMĀNA Collective
npm install && npm run dev
- Edit `src/config/site.ts` (WhatsApp number, email, location) and `src/data/products.ts` (products and categories).
- Put product photos in `public/images/products/` and reference them in `images`.
- Email delivery: copy `.env.example` to `.env.local` and fill in Resend credentials. Without it the form falls back to WhatsApp.
- Not built yet: admin dashboard/CMS (products.ts is a CMS-ready shape), GSAP, cursor trail, loader.
